# AI Usage Report (Assignment 2)

## Tools Used and Use Cases
### ChatGPT
I used ChatGPT as an AI learning assistant throughout this assignment. It helped me review the assignment requirements, divide the work into manageable steps, understand the purpose of different files and folders, and receive explanations about HTML, CSS, JavaScript, Git, and GitHub. I also used it to review my code, identify mistakes, and understand why particular elements, properties, and methods were used.

I also used ChatGPT to improve the writing in my portfolio and documentation. It helped me organize my ideas and revise my wording so that the information was clear, concise, and easy to understand. I reviewed the revised writing and changed it when necessary to ensure that it accurately represented my experience and learning process.

## Benefits and Challenges
ChatGPT helped me organize the assignment, understand unfamiliar concepts, identify mistakes, and complete each requirement in a clear order. The explanations helped me understand why specific HTML elements, CSS properties, and JavaScript statements were used instead of only giving me a finished solution. This saved time while still allowing me to build and test the website myself.

One challenge was that some initial suggestions included concepts that were more advanced than what I had covered in my course. I had to ask for simpler explanations and replace some suggestions with code that I could understand.

## Learning Outcomes
The most important outcome of this assignment was learning how to build a complete project from scratch. I created a public GitHub repository, organized the folders and files, and developed each part step by step. By asking why each element, file, and property was needed, I developed a better understanding of project structure and common web development practices.

I learned how media queries adjust the layout for desktop, tablet, and mobile screens. I also used Chrome DevTools to test responsiveness. In JavaScript, I learned how to select an HTML element, retrieve the current time, and change visible text.

## Responsible Use and Modifications
I did not use AI suggestions without reviewing them. I asked questions to understand the code, typed and tested the implementation myself, and requested simpler alternatives when a suggestion was beyond my current knowledge. I also changed the content, design, and code to match my experience, preferences, and course level. I used AI as a learning and review tool while remaining responsible for the final decisions and submitted work.
